# E-Commerce

Full-stack E-Commerce Platform built with Laravel, Inertia, Vue 3, Nuxt 3, and Sanctum.

## Features
- **Storefront**: Dynamic Products, Categories, Cart, Guest Checkout, Payment Gateways (bKash, Nagad, SSLCommerz, COD).
- **Admin Panel**: Dashboard, Order Operations, Flash Sales, Shipping Zones, Logistics & Courier Dispatch (Pathao, Steadfast, Paperfly, RedX), RBAC Roles & Permissions.
- **Backend API**: Laravel RESTful APIs with Sanctum Token Authentication, Failover Cache & Redis Queue.
